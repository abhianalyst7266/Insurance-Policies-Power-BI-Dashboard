**Insurance Policies Data Analysis Dashboard using Power BI**
**Project Overview**
This project presents an interactive Insurance Policies Data Analysis Dashboard developed using Microsoft Power BI. The dashboard helps analyze insurance claims, customer demographics, vehicle information, education levels, marital status, and claim distribution.
The objective is to transform insurance data into meaningful insights that can help understand customer behavior, identify claim patterns, and support data-driven insurance business decisions.

**Dashboard Features**
_The dashboard includes the following visualizations:_
 - Claim Count by Age Group
 - Claim Amount by Number of Kids Driving
 - Claim Count by Car Manufacturing Year
 - Claim Amount by Education and Marital Status
 - Claim Count by Car Usage (Private and Commercial)
 - Claim Count by Car Make
 - Claim Amount by Education Level
 - Gender-wise Claim Distribution

**Key Insights**

 - The dashboard contains approximately 37.54K records based on the ID count.
 - The average claim amount is approximately 5.00K.
 - The 31–50 age group has the highest claim count at 14.1K.
 - The 51–65 age group contributes 10.6K claims.
 - Private car usage accounts for approximately 30.06K claims, compared with 7.48K for commercial usage.
 - Customers with zero kids driving contribute the highest displayed claim amount of 134M.
 - Bachelor's degree holders have the highest claim amount among the displayed education categories, at approximately 94M.
 - The dashboard also provides insights into gender distribution, car manufacturers, marital status, and claim trends by vehicle year.

**How to Use**
 - Download or clone this repository.
 - Open the .pbix file using Microsoft Power BI Desktop.
 - If required, update the dataset source path.
 - Refresh the data.
 - Explore the interactive dashboard using filters and visualizations.

**Business Objective**
The main objective of this project is to help insurance businesses understand customer demographics, analyze claim patterns, compare vehicle-related claims, and explore the relationship between customer characteristics and insurance claims.
The dashboard provides an interactive way to explore insurance data and generate meaningful business insights.
